## 🏛️ Ecosystem Architecture

VagusHQ researches low-demand, non-clinical autonomic self-regulation systems and sensory-safe digital interfaces. This repository serves as our public open-access hub for design specifications, research whitepapers, and interactive web tools.

* **Official Knowledge Hub:** [https://www.vagushq.com](https://www.vagushq.com)
* **Interactive Pathways Explorer:** [https://pathways.vagushq.com](https://pathways.vagushq.com)
* **Editorial Dispatch:** [https://vagushq.substack.com](https://vagushq.substack.com)

---

## 📦 Repository Contents

1. **`01_RESEARCH_PAPERS/`**:
   * `LOW_DEMAND_SENSORY_ACCESSIBILITY_SPECIFICATION.md`: The ADS V2.1 design system specification for building low-arousal, low-demand software interfaces.
2. **`02_PUBLIC_TOOLS_AND_DATA/`**:
   * `high_intent_neurodiversity_lexicon.json`: Open taxonomy of non-pathologizing, sensory-affirming terminology.
3. **`docs/`**:
   * `index.html`: Fully self-contained, client-side somatic focus pacer and autonomic check-in tool hosted live via GitHub Pages.
